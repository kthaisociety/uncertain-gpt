A posterior over the weights of a transformer is paid for in GPU memory and
GPU time. This paper prices four of them against each other on one network,
one corpus and one card.

Bayes-by-Backprop \citep{blundell2015weight}, Vadam \citep{khan2018vadam}, a
learned low-rank-plus-diagonal Gaussian posterior, and a deep ensemble
\citep{lakshminarayanan2017simple} share a single CUDA implementation of GPT-2
\citep{radford2019language}: the same kernels, the same forward and backward
pass, the same batches in the same order, the same AdamW hyperparameters, the
same precision. Each method's source file contains only how it draws a weight
vector and how it updates the parameters behind that draw, and everything else
lives in one shared header. Any difference between two arms is the posterior.

In CUDA a posterior is a count of parameter-sized buffers and a count of kernel
passes over them, and cost is reported in those units and in milliseconds per
step. Quality comes from one harness shared by all four arms.
