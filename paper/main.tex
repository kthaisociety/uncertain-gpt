\begin{abstract}
% What the paper measures and on what. One controlled comparison: four
% posterior approximations, one shared network, one card. Every claim here
% has to be a cell in a generated table or a constant from the source.
Four uncertainty methods, one CUDA implementation of a GPT-2, one card.
Bayes-by-Backprop, Vadam, a learned low-rank-plus-diagonal Gaussian posterior
and a five-member deep ensemble share the same kernels, the same batches in
the same order and the same optimiser constants; each method's source file
holds only how it draws a weight vector and how it updates the parameters
behind that draw. Cost is measured in parameter-sized buffers, VRAM and
milliseconds per training step, quality through one harness reporting NLPD,
expected calibration error and an aleatoric/epistemic decomposition gated by
an exact algebraic identity, on $11$M parameters trained for $100{,}000$ steps
of character-level text8.

The ensemble has the best predictive quality and the worst calibration, and
separates in- from off-distribution input by more than twice the margin of
any variational arm. Vadam holds the opposite corner: cheapest posterior,
best calibration, worst predictive quality, its posterior scale left at the
prior because the dataset size enters the precision as $N s$ against
$\lambda$. Converging the sample count $S$ \emph{widens} the ensemble's
separation advantage, since under-sampling suppresses in-distribution
epistemic uncertainty more than off-distribution; a separation ratio quoted
without its $S$ cannot be read. Step times are lower bounds on one thermally
limited card and the off-distribution stream is synthetic, so what is measured
is the ratio between arms on one implementation, not a claim about scale.
\end{abstract}
